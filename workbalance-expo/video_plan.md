# WorkBalance Expo — Plan de Videos con Higgsfield AI
**Modelo:** Tu modelo de IA (foto propia, ya tienes)
**Formato:** Vertical 9:16 (TikTok / Instagram Reels)
**Duración por escena:** 8 segundos
**Total:** 3 videos, cada uno con 3-4 escenas

---

## HERRAMIENTAS HIGGSFIELD A USAR

- **Modelo de video:** Kling 3.0 (mejor consistencia de personaje, ideal para modelo real)
- **Image-to-Video:** Subir foto de tu modelo y animar con prompt
- **Motion Control:** Para controlar exactamente qué hace el cuerpo/cara
- **Camera Controls:** Librería de 50+ movimientos cinematográficos
- **Soul 2.0:** Para las fotos base (si necesitas generar imágenes del modelo en distintos escenarios)
- **Edición final:** Remotion para captions animados, overlays, música y logo

## FLUJO DE PRODUCCIÓN RECOMENDADO

1. Tomar fotos base del modelo (o usar las que ya tienes)
2. Subir foto a Higgsfield → Image to Video → Kling 3.0
3. Pegar prompt de cada escena + seleccionar movimiento de cámara
4. Descargar los clips de 8 segundos
5. Pasar por Remotion para: captions animados, logo WBE, música de fondo, transiciones entre escenas
6. Exportar en 9:16 1080×1920 para TikTok e Instagram
